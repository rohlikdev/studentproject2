## ENGLISH
## Steps for setting up the PostgreSQL database



1\. Open the PostgreSQL application pgAdmin 4

2\. Create a new database named "rezervace\_db"

3\. Right-click on the newly created database and select "Backup..."

4\. Set the format to "Plain"

5\. Click the file browser button next to "Filename"

6\. Select "All files" at the bottom of the file browser window

7\. Select the "rezervace" database file

8\. Click the blue "Backup" button in the bottom-right corner

9\. Done



(To view the data in the database, navigate to "rezervace\_db" -> "Schemas" -> "Tables" -> "reservations" / "rooms" (Right-click -> View/Edit Data -> All Rows))





\----------------------------------------------------------------------





Useful information:



user: 'postgres',

host: 'localhost',

database: 'rezervace\_db',

port: 5432,

## Steps for Web Setup



1\. Use the "cd" command to navigate to the directory "/Desktop/FOLDER\_NAME/FOLDER\_NAME/src/backend"

2\. Start the server using "node server.js"

3\. Launch the live server for "index.html"

4\. Done
